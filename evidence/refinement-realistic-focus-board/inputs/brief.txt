Build a polished browser-based daily focus board for a person managing a short list of tasks. They should be able to add tasks, mark them complete, filter all/active/completed items, remove individual tasks, and clear completed work. Preserve the list across reloads with local browser storage. Support efficient keyboard use as well as touch, responsive desktop and mobile layouts, concise instructions, readable accessible controls, visible focus states, and a cohesive calm visual design. Run locally with no account, backend, external service, dependency installation, or deployment.
